# Le déphasage à l’oscilloscope

**→ https://temmchen.github.io/dephasage/**

Animierte Unterrichtspräsentation zur **Phasenverschiebung** zweier Wechselgrößen am Oszilloskop –
Klasse 1GIGF, Modul ELETE, LTEtt, Schuljahr 2026/27 (Tom Bleyer). Sprache der Folien: Französisch.

- Eine einzige Datei (`index.html`), keine externen Bibliotheken – läuft in Safari, Chrome, Firefox und Edge,
  auf **iPad** und **Computer**.
- 34 Folien, 2 Filme, φ-Schieber, Labor-Oszilloskop mit Übungsmodus, Quiz.
- Schülerfassung: ohne Sprechernotizen und Referentenansicht.
- **Zugang mit Klassenpasswort** (zeigt der Lehrer mit dem QR-Code). Die Seite ist mit AES-256-GCM verschlüsselt
  (PBKDF2-SHA256, 600 000 Runden) – im Repo liegt nur das Chiffrat. „Rester connecté“ merkt sich den Schlüssel im Browser.

## Bedienung

| iPad | Computer | Wirkung |
| --- | --- | --- |
| nach links wischen · › | → · Leertaste | weiter |
| nach rechts wischen · ‹ | ← | zurück |
| ▦ | O | Übersicht aller Folien |
| ⛶ | F | Vollbild |
| — | A | Quiz: Lösung zeigen |

Tipp fürs iPad: in Safari *Teilen → Zum Home-Bildschirm* – dann startet die Präsentation wie eine App im Vollbild.

## Section française

Présentation animée sur le **déphasage** de deux grandeurs alternatives à l’oscilloscope – classe 1GIGF,
module ELETE, LTEtt, année scolaire 2026/27 (Tom Bleyer).

- Ouvrir : **https://temmchen.github.io/dephasage/** (iPad, ordinateur, tous les navigateurs récents),
  puis entrer le **mot de passe de la classe** (affiché en classe avec le code QR).
- Avancer : balayer vers la gauche, bouton › ou flèche → / espace ; reculer : balayer vers la droite, ‹ ou ←.
- ▦ ou O : vue d’ensemble · ⛶ ou F : plein écran · A : solution du quiz.
- Sur iPad : *Partager → Sur l’écran d’accueil* pour l’ouvrir en plein écran comme une app.
